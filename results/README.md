# Results

ผลการทดลอง (CSV, confusion matrix, กราฟ) จะบันทึกไว้ที่นี่ ไฟล์ทั้งหมดถูก git ignore ยกเว้นไฟล์นี้ ถ้าต้องการเก็บตารางสรุปผลสุดท้ายไว้ใน repo ให้ `git add -f` เฉพาะไฟล์นั้น

รูปแบบ CSV ที่วางแผนไว้: หนึ่งแถวต่อหนึ่ง run มีคอลัมน์ `dataset, feature, model, seed, epochs, macro_f1, balanced_acc, auc, icbhi_score`
