## สรุปสั้น

| คำถาม | คำตอบ |
|---|---|
| report ตอนนี้ (`demo_report_synthetic.html`) ใช้ได้จริงไหม | **ใช้ได้แค่โชว์ว่า pipeline ทำงานครบ** ตัวเลขทุกตัวมาจากข้อมูลสังเคราะห์ ไม่มีความหมาย ห้ามใช้สรุปผล |

| อาจารย์จะเห็นความเปลี่ยนแปลงไหม | เห็นชัดในส่วนการออกแบบ: setting เดียวกันทุกวิธี, คู่เทียบ 6 งาน, ablation ครบทุกเทคนิค ส่วนผลด้านความแม่นยำจะเห็นได้หลังรันกับข้อมูลจริง |

## แต่ละส่วนของ report บอกอะไร

**กล่องด้านบน:** บอกว่าเป็น demo (กี่ epoch, seed เดียว) และ setting ที่ใช้เหมือนกันทุกวิธี: ICBHI 4 คลาส, official split, validation แยกผู้ป่วย, band-pass 120–1800 Hz, augmentation เฉพาะ train, เลือก epoch จาก validation แล้วเปิด test ครั้งเดียว ถ้าผลมาจากข้อมูลสังเคราะห์ กล่องจะเป็นสีแดงพร้อมคำเตือน

1. **โมเดลที่เสนอ เทียบคู่เทียบ 6 งาน:** กราฟแท่ง ICBHI score และ macro-F1 แต่ละวิธีมีสีประจำตัว (ใช้สีเดียวกันทุกกราฟ) และตารางที่มี Se, Sp, F1 รายคลาส, จำนวนพารามิเตอร์, เวลาฝึก ตอบ RQ1: โมเดลที่เสนอดีกว่าคู่เทียบไหมภายใต้ setting เดียวกัน
2. **Ablation 11 แบบ:** แต่ละแท่งคือคะแนนเมื่อตัดหรือเปลี่ยนเทคนิคหนึ่งอย่าง ลบด้วยคะแนนของโมเดลที่เสนอ แท่งแดง (ติดลบ) = ตัดออกแล้วแย่ลง แปลว่าเทคนิคนั้นช่วย แท่งเขียว = ยังไม่เห็นประโยชน์ ตอบ RQ2 และคำถาม "เทคนิคที่เลือกช่วยจริงไหม"
   - feature: ตัด MFCC + ΔMFCC (Mel อย่างเดียว), ตัด ΔMFCC
   - pretrain: ImageNet แทน AudioSet, ไม่ pretrain เลย
   - fusion: ต่อ embedding ตรงๆ แทน SE gating
   - preprocessing: ไม่ band-pass, PCEN แทน log-Mel
   - การฝึก: ไม่ SpecAugment, ไม่ mixup, ไม่ถ่วงน้ำหนักคลาส, ไม่ drop path
3. **F1 รายคลาส:** ดูว่าแต่ละวิธีเก่ง crackle / wheeze / both ต่างกันอย่างไร คลาส both มีตัวอย่างน้อยที่สุด มักได้คะแนนต่ำ
4. **Confusion matrix:** โมเดลที่เสนอ เทียบกับ Mel อย่างเดียว ดูว่าการเพิ่ม MFCC + ΔMFCC ลดการทายผิดระหว่างคลาสไหน
5. **ICBHI score บน validation ระหว่างฝึก:** ดูว่าแต่ละวิธียังเรียนรู้อยู่ไหม ถ้าเส้นยังขึ้นตอน epoch สุดท้าย แปลว่า 5 epoch ยังไม่พอ ผลเทียบกันจึงยังไม่ยุติธรรม

## สิ่งที่เปลี่ยนจากเวอร์ชันก่อน (จุดที่ควรชี้ให้อาจารย์เห็น)

- **เปลี่ยนแนวทาง:** จาก benchmark ข้ามประเภทเสียง (ESC-50) มาเป็นเสียงปอดแบบแยกผู้ป่วย (patient-independent) ตาม RD_v2
- **เทียบอย่างยุติธรรม:** คู่เทียบ 6 งานทำซ้ำในโค้ดเดียวกัน ข้อมูล split และ preprocessing ชุดเดียวกัน ไม่ได้ยกตัวเลขจากเปเปอร์มาเทียบตรงๆ
- **ablation ครบทุกเทคนิค:** จากเดิม 3 แบบ (Mel อย่างเดียว, ไม่มี Δ, ImageNet) เป็น 11 แบบ ครอบคลุมทุกเทคนิคที่เลือกใช้
- **metric ตามมาตรฐาน ICBHI:** ICBHI score, macro-F1, F1 รายคลาส, confusion matrix, จำนวนพารามิเตอร์และเวลา
- **แผนสถิติพร้อมแล้ว:** 5 seeds, paired t-test ทางเดียว + Holm, Friedman + Nemenyi ข้าม dataset (`python -m src.stats`)

## ข้อจำกัดของ demo ที่ต้องบอกอาจารย์ตรงๆ

- ฝึกแค่ 5 epoch (ของจริงสูงสุด 50 + early stopping) โมเดลใหญ่ที่ pretrain กับโมเดลเล็กอาจยังลู่เข้าไม่เท่ากัน
- seed เดียว ผลบน ICBHI แกว่งได้หลาย % ระหว่าง seed และยังไม่ได้ทดสอบสถิติ
- ใช้แค่ ICBHI ยังไม่ได้รัน KAUH และ HF_Lung_V1 (RQ3)
